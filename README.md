# ID3 v2.4 → v2.3 変換ツール (Android)

## 概要

Android上で動作するMP3ファイルのID3タグバージョン変換ツールです。
Sony Walkman（Android搭載）の音楽プレイヤーがID3v2.3にのみ対応しているため、
ID3v2.4のタグをv2.3に変換します。

## 機能

- 指定したフォルダ内のMP3ファイルを再帰的に検索
- ID3v2.4タグをID3v2.3に変換
- 変換後の保存方法を選択可能:
  - 元のファイルに上書き保存
  - 別ファイル名で保存（ファイル名に`_v23`を付加）
- **中断・再開機能**: 変換を途中で止めて次回続きから再開可能
- 進捗はアプリ内部ストレージに保存（アプリ再起動後も保持）
- 変換の進捗とログをリアルタイム表示
- 大規模ライブラリ対応（30,000曲以上でのテストを想定）

## 技術仕様

- **最小SDK**: Android 8.0 (API 26)
- **ターゲットSDK**: Android 14 (API 34)
- **言語**: Kotlin
- **ID3タグ操作**: JAudioTagger 3.0.1
- **UI**: Material Components

## ビルド方法

1. Android Studioでプロジェクトを開く
2. Gradle Syncを実行
3. Build > Make Project
4. Run でデバイスにインストール

## 使い方

1. アプリを起動
2. 「フォルダを選択」ボタンでMP3ファイルが入ったフォルダを選択
3. 保存方法を選択（上書き or 別名保存）
4. 前回の続きから再開する場合はチェックボックスをオンにする
5. 「変換開始」ボタンをタップ
6. 確認ダイアログで「変換開始」をタップ
7. 途中で止めたい場合は「中断」ボタンをタップ（進捗は自動保存）

## 中断・再開について

大量のMP3ファイルを変換する際、途中で中断して後日再開できます:

- 変換中に「中断」ボタンをタップすると安全に停止
- 進捗はファイル単位で即座に保存される
- 次回同じフォルダを選択し「前回の続きから再開する」にチェックを入れて開始
- 変換済みファイルは自動的にスキップされる
- 「進捗をクリア」ボタンで最初からやり直すことも可能

## 注意事項

- Android 11以降では「すべてのファイルへのアクセス」権限が必要です
- 上書きモードでは元のファイルが変更されるため、事前にバックアップを推奨します
- ID3v2.4以外のタグを持つMP3ファイルはスキップされます
